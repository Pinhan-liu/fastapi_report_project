# AI-NetTune

**基于 LLM 意图驱动的多模态无线网络智能监测与辅助分析平台**

面向多接入点无线组网（5G 现网 / 校园 / 商场等）场景的 Web 智能监测平台：让**不懂通信 KPI 的人**也能通过自然语言对话，看懂网络状态、问出故障原因、拿到处置建议，并结合位置感知与电磁频谱分析，获得 "哪里信号好、如何移动" 的信号导航指引。



***

## 项目简介

本项目将大语言模型（LLM）智能体意图驱动思想迁移至无线网络监测领域：



* **数据层**：支持仿真数据生成与 CSV 导入，模拟多接入点、多用户无线组网监测场景（11 维数据字典，含网络状态标签，见 [docs/data\_dict.md](docs/data_dict.md)）；

* **智能层**：内置通信 KPI 语义层，将 RSRP、SINR、吞吐量等专业指标翻译为自然语言；多 KPI 联合研判引擎结合通信专业知识输出**可解释**的故障结论（覆盖故障 / 网络拥塞 / 边缘弱用户）；融合位置感知与电磁频谱分析，预测区域信号质量分布，提供信号导航指引；

* **交互层**：用户通过自然语言提问，即可完成数据查询、故障研判、报告导出，并输出**文本、图表、地图多模态**研判结果；

* **可靠性**：大模型仅负责语义理解，数据运算交由确定性工具执行，规避幻觉问题；大模型 API 不可用时，传统监测、告警、可视化功能可降级使用。

## 功能特性



* ✅ 通信 KPI 可视化（折线图 / 信号热力图 / 网络拓扑图 / 频谱地图）

* ✅ 区域信号质量预测与信号导航指引（位置感知 + 电磁频谱分析）

* ✅ 多 KPI 联合故障研判，输出 "故障类型 → 证据链 → 原因 → 处置建议"

* ✅ 自然语言对话式监测（LLM 意图识别）+ 文本 / 图表 / 地图多模态输出

* ✅ 分析报告导出

* ✅ 仿真数据生成 + CSV 导入

* 🚧 React + TypeScript 前端（前后端联调中）

## 快速开始

### 后端（当前已可运行）



```
\\# 1. 安装依赖

python -m pip install fastapi uvicorn pandas

\\# 2. 启动服务（局域网联调用 0.0.0.0）

python -m uvicorn main:app --reload --host 0.0.0.0
```

浏览器打开 [http://localhost:8000/docs](http://localhost:8000/docs) 查看 Swagger 接口测试面板。

> 当前接口返回模拟数据用于跑通链路，后续将接入真实仿真数据与研判逻辑。

### 前端（联调中）



```
cd frontend

npm install

npm run dev
```

## AI‑NetTune 项目数据字典
> 文件说明：本文件为团队开发契约文档，定义CSV仿真网络数据集字段规范，后端、仿真脚本、前端开发以此文档为准。
> 
| 列名           | 含义             | 单位                | 类型     | 取值 / 枚举                       | 说明                 |
| -------------- | ---------------- | ------------------- | -------- | --------------------------------- | -------------------- |
| timestamp      | 采样时间         | yyyy-MM-dd HH:mm:ss | datetime | 2026-01-01 ~ 2026-01-02           | 指标采样时间戳       |
| ap_id          | 接入点编号       | -                   | str      | AP-01、AP-02、AP-03               | 无线接入点 ID        |
| user_id        | 用户编号         | -                   | str      | UE-001 ~ UE-010                   | 终端用户 ID          |
| rsrp           | 参考信号接收功率 | dBm                 | float    | -140 ~ -60                        | 信号越强数值越大     |
| sinr           | 信干噪比         | dB                  | float    | -10 ~ 30                          | 信号质量，越高越好   |
| throughput     | 吞吐量           | Mbps                | float    | 0 ~ 1000                          | 用户下行速率         |
| latency        | 时延             | ms                  | float    | 1 ~ 500                           | 端到端网络延迟       |
| packet_loss    | 丢包率           | %                   | float    | 0 ~ 100                           | 数据包丢失百分比     |
| prb_usage      | PRB 利用率       | %                   | float    | 0 ~ 100                           | 无线资源块占用率     |
| scenario       | 场景标签         | -                   | str      | 校园、商场、体育馆                | 物理部署地点场景     |
| network_status | 网络状态         | -                   | str      | normal、congestion、weak_coverage | 正常 / 拥塞 / 弱覆盖 |

完整字段规范见 [docs/data\_dict.md](docs/data_dict.md)。
